# Open Family Office v0.5.0

Open Family Office v0.5 turns the project from a source-checkout-oriented toolkit into an **installable, agent-first local Family Office workspace**.

The core idea remains the same:

> Your portfolio is not your whole financial life.

This release keeps the advanced machinery — household accounting, ownership look-through, scenarios, quantitative research, provider adapters and optional MCP — while making the default experience much simpler.

## Install

### Try without cloning

```bash
uvx --from git+https://github.com/JamesbbBriz/open-family-office.git ofo demo --open
```

### Install the CLI

```bash
uv tool install git+https://github.com/JamesbbBriz/open-family-office.git
```

Then create a private workspace:

```bash
ofo init ~/FamilyOffice
cd ~/FamilyOffice
ofo status
```

## Highlights

### Standalone `ofo` CLI

The built wheel now includes:
- synthetic demo fixtures;
- household templates;
- portable Agent Skills;
- canonical workflows;
- offline dashboard resources.

A normal user no longer needs a Git checkout for day-to-day use.

### Private workspace onboarding

`ofo init` creates a private Family Office directory with:
- household model;
- evidence/import/scenario/report folders;
- portable Agent Skills;
- Claude entrypoints;
- canonical workflows/methodology/schemas.

The CLI discovers the workspace automatically, so common commands stay short.

### Skills as the UX

The default user-facing Skill surface is:

- `ofo-demo`
- `ofo-start`
- `ofo-update`
- `ofo-overview`
- `ofo-plan`
- `ofo-scenario`
- `ofo-research`
- `ofo-dashboard`
- `ofo-review`
- `ofo-doctor`

Granular financial procedures remain under `agent/workflows/` for contributors and Agent orchestration.

### Safe Agent-kit upgrades

```bash
ofo agent sync
```

Unmodified managed files can be upgraded automatically. User-edited Skills/workflows are preserved and reported as conflicts instead of being overwritten.

### MCP is optional

MCP remains a read-only interoperability layer for compatible Agent hosts. It is not required for normal CLI or Skill use.

```bash
ofo mcp-config
```

The generated configuration is scoped to the explicitly authorized private workspace.

### Offline dashboard

```bash
ofo dashboard --out reports/review.html --open
```

The exported HTML is standalone and embeds the household data it visualizes. Keep private reports private.

## Advanced research

Optional capabilities continue to include:
- ownership look-through;
- liquid-sleeve optimization;
- Monte Carlo simulation;
- SEC EDGAR, FRED, RBA, ABS, OECD, IMF, CoinGecko, Yahoo/yfinance, OpenBB, Alpha Vantage, Finnhub, MarketData.app and MetalpriceAPI adapters.

Provider adapters remain explicit and network-off by default. Adapter code is not a claim of live entitlement or successful authentication.

## Project boundary

Open Family Office is a research and decision-support toolkit.

It does not:
- execute trades;
- move money;
- log into banks;
- file tax returns;
- automatically select financial products.

Quantitative outputs are conditional on supplied inputs and assumptions.

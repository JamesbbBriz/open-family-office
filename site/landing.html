A FEW THINGS TO KNOW
Can people try this online and use it offline?

Yes. Publish the supplied public folder to static hosting for an online demo. Or download the HTML and open it locally. All scripts, styles and demo data are embedded. For links between the landing page and demo, keep the website ZIP’s files together.

Does the website run an AI agent or connect my bank?

No. It offers precomputed research charts and an independent in-browser cash calculator. Agent workflows, private imports and provider requests run separately in your local setup. There is no login, background sync or trading on this site.

Are the numbers real market data or recommendations?

No. The public example is entirely synthetic. Scenario shocks and return assumptions are explicit inputs, not predictions. The calculator models cash only; it does not recommend investments or automatically value a business.

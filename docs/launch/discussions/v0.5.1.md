v0.5.1 packages the v0.5 experience into a reproducible distribution path.

- installable `ofo` CLI plus `open-family-office` alias;
- private workspace onboarding;
- 10 user-facing portable Agent Skills;

- offline dashboard export;
- optional read-only MCP;

- official MCP Registry metadata and CI validation;
- GitHub Pages deployment workflow;
- clean-wheel tests outside the source checkout.

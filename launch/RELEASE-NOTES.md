# Open Family Office v0.2.0

Your portfolio is not your whole financial life.

This release connects a workflow-first family wealth research project to explicit data-adapter source, liquid-sleeve quantitative tools and a five-view offline financial dashboard. The report includes 13 interactive Tailwind/Plotly charts, four synthetic household scenarios, dark/light modes and export/print controls.

The cash-flow examples distinguish recurring income from a business-sale cash event, remove the disposed equity value and stop its distributions. Research adds SciPy methods, optional skfolio/PyPortfolioOpt bridges, explicit-input Monte Carlo, ownership consolidation and exposure summaries. The repo includes 16 skills and seven read-only MCP tools.

Important release boundary: numerical and browser tests were executed; provider contract fixtures were tested; native optional SDKs, the complete installer, actual agent/MCP host handshakes and real external provider calls were not all exercised. There are no live feeds, paid data entitlements, bank connections or trade execution in the demo. See docs/VALIDATION.md and docs/INTEGRATIONS.md.

Open public/demo.html to explore; run python scripts/bootstrap.py --all to install the source stack on a supported machine. Private data and outputs belong outside the repository.

# Repository discovery settings

These are the canonical public-discovery values for the GitHub repository.

## About description

> Local-first open-source family wealth research for people and AI agents: cash flow, asset allocation, scenarios, ownership look-through and more.

Keep this description short enough to remain readable in GitHub search and repository cards.

## Homepage

Until a hosted demo is deployed, leave the Homepage field empty rather than pointing to a fake or temporary URL.

When a stable public demo exists, use that URL.

## Social preview

Use:

```text
assets/social-preview.png
```

Recommended GitHub path:

```text
Settings → General → Social preview → Edit → Upload an image
```

GitHub currently does not expose this repository setting through the connected repository actions used by this project, so the image is versioned in the repository as the canonical asset.

## Contributor discovery

The repository should always keep a small set of:
- `good first issue` tickets with narrow, testable scope;
- `help wanted` tickets for medium-sized architecture/domain contributions;
- acceptance criteria and explicit out-of-scope boundaries.

Do not create speculative backlog issues only to inflate activity.

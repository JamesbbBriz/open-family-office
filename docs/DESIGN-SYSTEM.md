# Open Family Office design system

A restrained green/ivory interface shared by the landing page and research dashboard. There are no remote font files, CDN runtime dependencies, tracking pixels or external stylesheets in the generated HTML.

## Actual daisyUI use

The free daisyUI v5 MIT source for button, card, badge and input components was retrieved from the official repository and reduced/modified for this interface. These components and their colour/size variants are compiled by the Tailwind 4.1.10 compiler into `site/tailwind.generated.css`. Project light/dark theme tokens live in `site/shared.css`. This is not a claim of using every daisyUI component or a successfully installed full npm distribution.

The modified source is `vendor/daisyui/components.source.css`; upstream blob identities and changes are recorded in `vendor/daisyui/README.md`; the full upstream notice is in `vendor/licenses/daisyui-MIT.txt`. The original blob identifiers identify the upstream originals, not the modified local file.

`package.json` declares daisyUI 5.7.42 for developers wishing to install the full package. The release compiler intentionally uses the reviewed vendored subset so both pages share the same version-controlled component behaviour. No complete transitive dependency lockfile is claimed.

## Charts

Plotly remains the renderer for 13 existing research charts and one independent browser cash-budget chart. daisyUI Charts is a separately sold collection of chart integrations, not part of the free component source. Its proprietary templates are not copied, bundled or required.

The landing-page small SVG plots the actual synthetic baseline monthly cash budget generated by the Python engine. It is not a fabricated investment-return curve. System fonts only; no bundled font binaries.

## Pages and output

`site/landing.*` and `site/dashboard.*` are source. `public/index.html` and `public/demo.html` are built outputs. The latter has embedded scripts/styles/data and an explicit content security policy denying network connections. The public folder contains synthetic material only.

Browser-specific compatibility requires testing. Current automated visual checks use Chromium; Safari/iOS native file preview and Windows configurations are not certified by this delivery.

# Data sources

The current source of truth is [INTEGRATIONS.md](INTEGRATIONS.md) and the machine-readable `providers/registry.json`. The dynamic `hh providers` command reports environment readiness without revealing key values. All 13 external adapters have source and fixture/request tests; none has a live validation claim in this delivery.

Manual household JSON, cash-flow CSV and normalized holdings CSV are local inputs. Public data is not automatically approved data. Source registration must document provider capability, endpoint, authentication, identifiers, units, original observation dates, revision semantics, use rights, retrieval evidence and mapping review.

A source's existence does not imply entitlement, accuracy or redistribution permission. Error responses never become synthetic market prices. Missing observations remain missing. Property/private-business valuations remain explicit assumptions or user-supplied statements, not inferred from a broad market index.

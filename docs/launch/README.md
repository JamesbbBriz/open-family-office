# Open Family Office launch kit

This directory contains ready-to-publish GTM copy and the exact asset mapping for the first public launch.

The order is deliberate:

1. make the demo reachable;
2. publish the Python package;
3. publish MCP Registry metadata;
4. finish GitHub repository settings;
5. launch to technical communities;
6. launch to broader product communities;
7. keep responding to issues and contributors.

## Core positioning

**One-line**

> Open-source, local-first Family Office methods for the whole household — not just the portfolio.

**Longer**

> Open Family Office models assets, debt, recurring and one-off income, liquidity, ownership, goals, scenarios and a separately declared liquid investment sleeve. It combines deterministic Python calculations with portable Agent Skills and an optional read-only MCP layer.

## Primary CTA order

1. **Try the demo**
2. **Install locally**
3. **View the GitHub repository**
4. **Open an issue / contribute**

Do not lead with “star the repo.”

## Success metrics

The useful funnel is:

```text
repository/demo visit
        ↓
demo opened
        ↓
CLI installed
        ↓
private workspace created
        ↓
issue / discussion
        ↓
external PR
```

Stars are useful discovery signals, but an external issue, install or PR is stronger evidence of product value.

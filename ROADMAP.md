# Roadmap

## Shipped: v0.2 source and offline report

Household accounting, cash-flow/disposal scenarios, private workspace boundary, 16 skills, 13 read-only adapter implementations, local quantitative research, graph/exposure tools, optional native SDK bridges and a five-view, 13-chart report.

## Next acceptance gates, not claimed shipped

Run the complete installer on clean macOS, Windows and Linux machines. Resolve and lock supported optional dependency versions. Validate actual skfolio/PyPortfolioOpt/OFX/MCP calls and agent-host discovery. Run opted-in, low-volume provider smoke tests with legitimate credentials, including the provisional IMF route. Record timestamps and provider changes without storing secrets or paid payloads.

## Data-to-research loop

Add reviewed instrument mapping and unit/date/FX normalization, caching with entitlement-aware retention, robust total-return construction, revision-aware macro vintages and persistent rate limits. Keep fresh/stale/missing distinct. Add N-PORT XML holdings ingestion with fixture coverage before claiming ETF lookthrough automation. Improve statement extraction with anchored evidence and explicit approval; OCR is not silently assumed available.

## Household analytics

Add transaction-ledger reconciliation, richer commitment timing, property/private-asset valuation ranges, tax/cost assumptions as versioned inputs, stress dependencies and transparent scenario sensitivity. Keep non-tradable wealth separate from the liquid investment decision set.

## Hosted, only after real adoption

Identity, encrypted storage, workspace permissions, access logs, data agreements, scheduling, region-specific product boundaries, operational monitoring and incident procedures. Stars alone are not product-market fit. No hosted deployment or regulatory classification is implied by this roadmap.

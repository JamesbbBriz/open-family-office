# Scenario discipline

Baseline and alternatives share dates, currency conventions and recorded obligations. Change only named assumptions.
A price shock changes a supplied valuation; it does not itself debit cash. A cashflow multiplier changes named
receipts or payments. Neither has an inferred probability. Joint shocks are assumptions, not empirical correlation estimates.

The business-equity sale bridge is:
event-only change in net worth = attributable after-tax cash received − attributable equity value removed.
Related recurring income stops in the settlement month. The engine does not assert a complete future balance
sheet: spending, amortisation, retained company earnings and asset returns are not projected into that bridge.

Unsupported: enterprise-value sales, property transfer taxes, retirement access rules, broker execution,
loan refinancing, deferred earn-outs and FX paths. Model extensions must identify new inputs and tests before use.

Run the bundled baseline, recession, income-stop and business-sale cases. A change in forecast cash may differ
from an immediate change in net worth; show both concepts rather than using an undifferentiated 'risk score'.
